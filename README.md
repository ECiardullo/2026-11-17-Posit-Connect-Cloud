# Posit Connect Cloud: publicación y uso compartido de proyectos de datos

**R en Buenos Aires | 17 de noviembre de 2026**

En este repositorio compartimos la grabación, las diapositivas y los recursos del encuentro virtual que organizamos desde **R en Buenos Aires** junto a **Isabella Velásquez (Developer Relations)** y **Alex Chisholm (Product Manager)** de Posit.

Durante el encuentro conocimos **Posit Connect Cloud**, sus principales funcionalidades para publicar y compartir proyectos desarrollados con herramientas de código abierto, y el proceso de migración desde shinyapps.io y Quarto Pub.

Somos una comunidad de práctica que promueve espacios gratuitos de encuentro, aprendizaje e intercambio de experiencias alrededor de R, la ciencia de datos y las herramientas de código abierto.
